# Projetos em C
Repositório criado para registrar meus estudos e práticas de programação
em C durante minha formação em Análise e Desenvolvimento de Sistemas.

## 📚 Conteúdos
Aqui estão exercícios, pequenos programas e projetos desenvolvidos
enquanto estudo os fundamentos da linguagem C.

Os códigos abordam conceitos como lógica de programação, estruturas
condicionais, estruturas de repetição, arrays, funções e outros
conceitos aprendidos ao longo dos estudos.

## 🎯 Objetivo
Registrar minha evolução no aprendizado de C e colocar em prática
os conceitos estudados.
